# LAYER 향수 유형 진단 로직 — 사용 설명서

## 1. 구조

이 워크북은 두 개의 축으로 6가지 향수 유형을 결정합니다.

- 축 A(존재감): 은은함 ↔ 확실함
  - Q2·Q3·Q4 응답으로 계산
- 축 B(태도): 한결같음 ↔ 탐험적
  - Q1·Q2·Q3·Q4·Q5 응답으로 계산
  - Q5의 가중치가 가장 큼

## 2. 시트 구성

- `유형정의`
  - 6개 최종 유형의 이름, 서브타이틀, 설명, 해시태그
- `질문별점수표`
  - Q1~Q5 전체 선택지
  - 각 선택지가 축 A/B에 주는 점수
- `결과계산기`
  - 실제 사용자가 고른 선택지를 입력하면 유형을 자동으로 산출
  - 개발 및 기획 검증용

## 3. 결과계산기 사용법

- 노란색 셀의 파란색 글씨 영역이 입력 칸입니다.
- Q1, Q4, Q5는 드롭다운에서 선택지 하나를 고릅니다. (단일 선택)
- Q2, Q3는 선택한 항목에 `1`, 선택하지 않은 항목에 `0`을 입력합니다. (복수 선택)
- 입력을 마치면 하단에 축 A/B 점수와 최종 유형이 자동으로 계산됩니다.

## 4. 실제 개발 반영 시

- `질문별점수표`의 점수를 서버 또는 클라이언트 로직의 상수로 그대로 옮깁니다.
- 축 A/B의 최종 판정 구간은 `결과계산기` 하단의 기준표를 따릅니다.

## 5. 구현 시 참고사항

- 이 문서는 워크북의 구조와 사용 방법을 설명하는 기준 문서입니다.
- 실제 선택지별 점수, 6개 유형의 상세 정보, 축별 판정 구간은 원본 워크북을 기준으로 구현해야 합니다.
- 원본 워크북이 추가되면 해당 파일의 `유형정의`, `질문별점수표`, `결과계산기` 내용을 결과 유형 페이지의 로직과 대조합니다.
